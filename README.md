# 2016 Election Forecast (FiveThirtyEight) — archival copy

A self-hosted, archival copy of FiveThirtyEight's 2016 general election
forecast, originally published at `projects.fivethirtyeight.com/2016-election-forecast/`.
FiveThirtyEight was shut down and its project URLs no longer resolve; this copy
was reconstructed from the [Internet Archive's Wayback Machine](https://web.archive.org/web/20180129013114/https://projects.fivethirtyeight.com/2016-election-forecast/)
so the work remains viewable. It reflects the forecast's final, post-election
state (frozen November 9, 2016).

I was part of the team that built it; this copy is hosted as part of my
portfolio. All content © FiveThirtyEight/ABC News. Not affiliated with or
endorsed by FiveThirtyEight, ABC News, or Disney.

Changes from the original: analytics/tracking scripts removed, asset URLs made
local, and links to now-dead FiveThirtyEight pages repointed at the Wayback
Machine.
